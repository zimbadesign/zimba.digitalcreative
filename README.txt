LANDING PAGE — HTML + CSS ONLY

FILES
- index.html ........ All real page content, navigation, texts, buttons and 12 portfolio images
- styles.css ........ Layout, colors, typography, background images, responsive behavior, CSS-only slider and :target mobile menu
- assets/ ........... All backgrounds, PNG icons, header/footer logos, favicon and portfolio photos
- robots.txt ........ Crawler access and sitemap discovery
- sitemap.xml ....... Canonical homepage and portfolio image URLs

HOW TO OPEN
Open index.html in a browser. No installation, server, JavaScript, frameworks or build tools are required.
To publish, upload index.html, styles.css, robots.txt, sitemap.xml and the entire assets folder to the public root of your hosting (for example, public_html).

INSTAGRAM

EDITING
- Edit all text, headings, and button labels directly in index.html.
- The first section is a 3-panel slider controlled by CSS and native HTML radio buttons (no JS).
- All section backgrounds are CSS background-image references in styles.css; they contain no section text.
- Services icons are separate PNG files in HTML, and service cards are drawn in CSS.
- The 12 portfolio projects are separate <img> tags in HTML, for browsing by scrolling only (no click-to-enlarge).
- Replace the portfolio files while retaining filenames if you want to update projects without changing HTML.
- The footer uses assets/logo-zimba-footer.png and the browser tab uses assets/favicon-zimba.png.
- Colors and typography are defined at the top of styles.css.
- The site uses the Google Fonts Poppins stylesheet when connected to the internet; system fonts are used as fallback.
- No executable JavaScript or JavaScript libraries are used. The JSON-LD script tag contains structured data only.
